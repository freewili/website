# Agent icons

These marks identify the coding agents AI Squared runs. Codex uses the OpenAI mark.

- `claude.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0 (see `LICENSE-simple-icons.txt`).
- `openai.svg` and `grok.svg`: [Lobe Icons](https://github.com/lobehub/lobe-icons), under MIT (see `LICENSE-lobe-icons.txt`).
- `ai2code.svg` is an original mark created for ai2code.
