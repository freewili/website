AI-native platform

AIAgent
Open hardware, UF2 Bootloader

This new age of AI means software like Claude Code can write and debug your embedded application the way you want it — without you having to master every low-level detail yourself. FREE-WILi 2 embraces that shift head-on.

Both Claude and LM Studio (for local models) are integrated directly in FREE-WILi GUI, so developers can reach cloud-based or fully offline AI assistance from the same tool they use to flash and debug the board. Open hardware documentation and AI Agent.md files make FREE-WILi 2 a platform where software is done by the user, for the user — not locked behind a proprietary toolchain. And when an agent needs to go all the way down to bare metal, the open WiliBSP board support package gives it a clean foundation for building complete custom firmware.
