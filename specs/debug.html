Integrated debug probe

IntegratedDebug
RPi Debug Probe Onboard, ESP32 JTAG

FREE-WILi 2 embeds an enhanced Raspberry Pi Debug Probe directly on the board, capable of flashing and debugging both RP2350s as well as the LoRa STM32 processor — all without reaching for an external programmer. The ESP32-C5 adds another layer: JTAG and serial output routed over USB, bringing in-the-box debug support to yet another on-board processor.

For customers building their own firmware — whether by hand or with the help of AI-assisted development — onboard debugging is a game-changer. Set a breakpoint, step through code, inspect memory: all the tools you’d expect from a professional bench setup, built right into the device you’re holding.
