WiFi & BT: ESP32-C5

ESP32C5
2.4/5GHz WiFi+BT

To support main stream wireless, the free wili includes the  ESP32-C5 Wireless microcontroller. The C5 revision supports both 2.4Ghz and 5 GHz WiFi support .  


The FREE-WILi 2 default firmware that provides access to the CLI over websockets or a webserver.

The ESP32 is completely open and supported by the FREE-WILi 2 UF2 bootloader.

The USB on the module connects to the onboard USB hub. ESP32C5 exposes a USB JTAG and COM port over this connection. This allows debugging to happen with all the ESP32 development tools. To make it easy to start - a tricolor LED is dedicated to the ESP32. These are on the exact same pins as the dev kit so SDK examples just work.

In an optional setup mode, the ESP32 can connect directly to the display and receive button input. In this mode ESP32 firmware can run without other CPUs. This makes is easier to run community applications which run on the ESP32.
