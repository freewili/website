Python API

PythonAPI
Runs on host or internal Linux

A single Python API drives FREE-WILi 2 from a host PC or from the onboard Linux CM0 — Linux drivers work identically to the Python API, so the same code runs wherever it is most convenient. The API pairs naturally with FREE-WILi GUI, giving developers a consistent path from rapid scripting to fully integrated tooling.

Full installation instructions, API reference, and examples are available in the online documentation — pip install freewili and you are ready to go.
