Dual RP2350 compute

RP2350
Dual MCU 16+8MByte

FREE-WILi launched at DEFCON 2024 — the very same day Raspberry Pi announced the RP2350, about 100 yards from the FREE-WILi booth in vendor village. FREE-WILi 2 closes that loop: both the main microcontroller and the display GPU are now RP2350s, closing the shortcomings of the RP2040 it launched with.

The RP2350 brings far more resources, more performance, and serious low-power capability — while staying mostly software-compatible with the RP2040 (it already powered last year’s ICS Village badge). Each CPU pairs dual cores with PIO programmable I/O for cycle-accurate bit-banging.

Both CPUs are augmented with 8 MB of serial SRAM and 16 MB of flash, so big buffers, frame data, and capture logs are no longer a squeeze.
