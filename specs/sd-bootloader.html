SD-card UF2 bootloader

SDCardBootloader
Load any RP2350 binary

The SD-card UF2 bootloader can load applications written by third parties onto the RP2350. Drop a UF2 file onto the microSD card and the board does the rest — no cables, no special tooling required.

Together with open hardware documentation and AI Agent.md files, this makes FREE-WILi 2 a genuine platform for running any code — software done by the user, for the user. The ecosystem is intentionally third-party friendly from the ground up.
