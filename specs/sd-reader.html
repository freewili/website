USB SD reader

SDCardreader
High speed USB SDCard reader onboard

The SD card in FREE-WILi 2 is run-time swappable between the main CPU and an integrated high-speed USB SD card reader. When handed to the reader, the card presents itself to any connected computer as a standard USB mass-storage device — fast transfers, broad OS support, no drivers needed. You can even launch FREE-WILi host software like FREE-WILi GUI directly from the card: a no-dependency, USB-drive-capable application that needs no installation.

The reader is also compatible with the Raspberry Pi Imager, so flashing a fresh image to the micro SD card is straightforward without hunting for a separate card reader or adapter — the hardware you need is already onboard.
