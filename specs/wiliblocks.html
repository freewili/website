WiliBLOCKS
Point & Click PARALLEL scripting

WiliBLOCKS brings point-and-click block sequential scripting to FREE-WILi.  You can have many WiliBlocks which all run in parallel. The Wiliblocks can run on the host PC, device or both. You can edit WiliBlocks on the host PC or on the FREE-WILi 2 display.
